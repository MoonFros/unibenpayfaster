# UNIBEN Microfinance Digital Payment Portal — Proposal Preview

A responsive, static visual prototype presenting a proposed digital payment journey for University of Benin students. The experience includes an overview landing page, a sample payment-details form, fictional payment destination, verification workflow, and a clearly watermarked sample receipt.

## Run locally

Open `index.html` in a browser, or serve the repository root with any static file server. No package installation or build step is required.

## Demonstration safeguards

- This is a non-functional UI/UX prototype; it has no backend, database, authentication, payment gateway, or external financial integration.
- The payment form updates only the on-page preview.
- The account number and transaction details are fictional placeholders. No funds can or should be transferred.
- The receipt is visibly marked as a sample/demonstration and is not a genuine financial record.

The project is a proposal preview and is not an officially commissioned or live UNIBEN Microfinance service.
